# Mobile App Development

## Install

```bash
cd mobile-app
npm install
```

## Start Expo

```bash
npm run start
```

## Run tests

```bash
npm run test
```

## Run typecheck

```bash
npm run typecheck
```

## Backend

The mobile app expects the existing backend to be running locally.
Default base URL:

```
http://127.0.0.1:3001
```

The backend exposes a `/health` endpoint for connectivity checks.
